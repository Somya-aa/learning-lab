# Git

Welcome to the **Git** section of the **Learning Lab** repository. This section is designed to help beginners understand Git from the ground up, covering everything from installation and repositories to branching, merging, GitHub workflows, and best practices.

Whether you're learning Git for the first time or revising key concepts, these notes provide clear explanations, practical commands, and helpful diagrams.

---

## 📚 Topics Covered

| No. | Topic | Description |
|:---:|-------|-------------|
| 01 | [What is Git?](01-What-is-Git.md) | Learn what Git is, why it was created, and how version control works. |
| 02 | [Installation](02-Installation.md) | Install Git and configure it for your development environment. |
| 03 | [Repository Basics](03-Repository-Basics.md) | Understand repositories, staging, commits, and the Git workflow. |
| 04 | [Branching](04-Branching.md) | Create, switch, and manage branches for independent development. |
| 05 | [Merging](05-Merging.md) | Combine branches, understand merge strategies, and resolve conflicts. |
| 06 | [Remote Repositories](06-Remote-Repositories.md) | Work with GitHub and other remote repositories using push, pull, fetch, and clone. |
| 07 | [GitHub Workflow](07-GitHub-Workflow.md) | Learn a standard GitHub collaboration workflow using Pull Requests. |
| 08 | [Git Commands](08-Git-Commands.md) | A quick reference for commonly used Git commands. |
| 09 | [Best Practices](09-Best-Practices.md) | Follow industry-standard Git practices for cleaner and more maintainable repositories. |

---

## 🛠 Prerequisites

Before starting this section, you should have:

- A computer with Git installed
- A basic understanding of using the terminal or command prompt
- A GitHub account (recommended)

---

## 📖 Learning Outcomes

After completing this section, you will be able to:

- Understand how Git works
- Track changes using version control
- Create and manage repositories
- Work with branches and merge changes
- Connect local repositories to GitHub
- Collaborate using Pull Requests
- Use essential Git commands confidently
- Follow Git best practices in real-world projects
